## Project Description
This project is a React Native messages directory app. The home screen displays a set of important directories: You, Home, Love, Family, Friends, and School. When the user taps a directory, the app displays stored messages for that selected directory.

## Main Features
- Built with React Native and TypeScript.
- Displays a responsive two-column directory grid.
- Each directory has a colorful card and label.
- Tapping a directory updates the message list.
- Messages are stored locally in a TypeScript array.
- Includes image assets and screenshots.

## How to Run
1. Install Node.js.
2. Install Android Studio and create an Android emulator.
3. Open Terminal in this project folder.
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the app:
   ```bash
   npm run android
   ```

If you only want to preview it first, run:
```bash
npm start
```
Then press `a` to open the Android emulator.
